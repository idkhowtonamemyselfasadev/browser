Browser

Fedora / RHEL / any dnf distro. Two commands, once:

sudo curl -o /etc/yum.repos.d/browser.repo https://idkhowtonamemyselfasadev.github.io/browser/browser.repo
sudo dnf install browser

After that: sudo dnf upgrade keeps it current. dnf pulls the Qt engine (python3-pyqt6-webengine) itself. The package is unsigned, so dnf asks you to confirm the repo once.

Browser

Pick your distro. Each is a one-time repo add, then install by name.

Fedora / RHEL / openSUSE (dnf, zypper)

sudo curl -o /etc/yum.repos.d/browser.repo https://idkhowtonamemyselfasadev.github.io/browser/browser.repo
sudo dnf install browser        # openSUSE: sudo zypper install browser

Ubuntu / Debian / Mint (apt)

echo "deb [trusted=yes] https://idkhowtonamemyselfasadev.github.io/browser/apt ./" | sudo tee /etc/apt/sources.list.d/browser.list
sudo apt update
sudo apt install browser

Arch / Manjaro

curl -O https://idkhowtonamemyselfasadev.github.io/browser/arch/PKGBUILD
makepkg -si

After that: your usual upgrade command keeps it current (dnf upgrade / apt upgrade). dnf and apt pull the Qt engine for you. Packages are unsigned, so the package manager asks you to trust the repo once.
